# Instructions for agents working on Frame

- Use Bun for package management and project scripts.
- When asked to install, set up, start, or connect Frame, read [setup.md](setup.md)
  and follow the path for the requested mode. Continue through startup and
  verification; do not stop after writing configuration or providing a plan.
- Reuse existing setup helpers and guides. Preserve user changes, existing
  configuration, database contents and erxes tenant bindings.
- Keep secrets out of command arguments, logs, chat, Git and browser bundles.
- Briefly explain tool actions and report only checks actually performed.
- Read any more specific `AGENTS.md` before modifying an erxes plugin or host.
- For product changes, search for an existing implementation before adding one;
  use relevant skills and prefer bold colors with strong contrast in UI design.
